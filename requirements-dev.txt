# 开发/测试依赖 —— 在 requirements.txt 之上再加这些。
#
# 为什么单独一个文件:`requirements.txt` 是**跑系统**要的;`pytest` 是**改系统**要的。
# 2026-09-27 实测踩到:照着开发者文档「装 requirements.txt → 跑 pytest」走,
# 第二步会 `No module named pytest` —— 文档里的两步接不上。这个文件就是补那个缝。
#
#   pip install -r requirements-dev.txt        # 开发/测试
#   pip install -r requirements.txt            # 只跑服务
#
-r requirements.txt

# 测试框架。**没有插件依赖** —— pytest.ini 只有 `testpaths = tests`,
# 测试里没有 `pytest.mark.asyncio` / `anyio` 之类需要额外插件的东西。
pytest>=8.0

# HTTP 测试客户端。`fastapi.testclient` → `starlette.testclient` 需要它:
#   starlette 优先 `import httpx2`,退回 `import httpx`(发一条 deprecation 警告),
#   两个都没有就 **RuntimeError**。2026-09-27 实测:服务器上两个都没装 ⟹ 3 条测试
#   直接收集失败(报 "requires the httpx2 package")。
# 装 starlette 自己点名要的那个,免得每次跑测试都吃一条 deprecation 警告。
httpx2>=2.0
