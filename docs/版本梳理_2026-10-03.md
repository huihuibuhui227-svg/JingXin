## 2. 处置方案(以服务器为准)

### 原则

1. **权威 = `~/JingXin/jingxin`(+ 它的 git)**。工作区根只该放两类东西:
   **另一个仓库**(`frontend/`)和**纯数据**(`recordings/`)。其余一律不留。
2. **历史不改**。`docs/superpowers/` 与 `.superpowers/` 里的 636 处旧路径**保留原样**
   —— 它们是"当时确实那么跑"的记录。要指路,在**活索引**里说明一次(已做,见 §3)。
3. **删副本,不合并**。副本是**旧快照**,不是"另一份各有价值的内容";
   合并会引入无法判定真伪的句子。以 git 里那份为准,副本删掉。

### 动作清单

| # | 动作 | 命令 / 说明 |
|---|---|---|
| 1 | 删 `jingxin/开发者文档.md`(未跟踪旧快照) | `git status` 会少一项 `??` |
| 2 | 删 `/home/zgy/JingXin/交接日志_2026-09-27.md`(仓库外散副本) | 与 `docs/` 版重复且更旧 |
| 3 | 工作区根加 `README.md` 说明三个目录各是什么 | 防下一个人再往根上放文件 |
| 4 | 修活文件的 117 处路径 | **逐个文件**改,不全局 sed |
| 5 | `.research-bench/`、`docs/ui-shots/` 归位或删 | 临时脚手架,确认无引用后清理 |
| 6 | `.env` 保持在仓库外(正确做法) | 它含 `JX_ADMIN_PASSWORD`,**不要移进仓库** |

> ⚠️ **动作 1/2 是删除**。三份副本都**从未进过 git**(未跟踪或在仓库外),
> 删掉不丢任何已纳管内容。但删文件不可逆,**执行前让使用者确认**。

## 4. 复核命令(数会变,别抄)

```bash
cd ~/JingXin/jingxin && ~/anaconda3/envs/jingxin/bin/python - <<'PY'
import re, pathlib, os, collections
pat = re.compile(r'(?:~|\$HOME)/[A-Za-z0-9_./\-]+')
HIST = ('docs/superpowers', '.superpowers', 'docs/复盘')
def expand(p):
    return pathlib.Path(p.replace('$HOME', str(pathlib.Path.home()))
                         .replace('~', str(pathlib.Path.home()), 1))
live, hist = collections.Counter(), collections.Counter()
for f in pathlib.Path('.').rglob('*'):
    if not f.is_file() or f.suffix not in ('.md', '.py', '.sh', '.json'):
        continue
    if any(p in f.parts for p in ('.git', 'node_modules', 'code_data_supplement',
                                  'experiments', '__pycache__')):
        continue
    ishist = any(h in str(f) for h in HIST)
    for m in pat.findall(f.read_text(encoding='utf-8', errors='ignore')):
        p = m.rstrip('.,;)`」）:')
        if expand(p).exists():
            continue
        (hist if ishist else live)[p] += 1
print('历史账本', sum(hist.values()), '处 / 活文件', sum(live.values()), '处')
for p, c in live.most_common(15):
    print(f'  {c:4}×  {p}')
PY
```
