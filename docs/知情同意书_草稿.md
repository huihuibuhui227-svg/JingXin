## 一、这是什么

本页说明:你在本次面试中会被记录什么、用来做什么、留多久、你有哪些权利。

**系统是什么**:一套**结构化行为观测**工具。它记录你在面试中的发言内容、面部与姿态的
可测变化、语音的声学量,并生成一份**行为观测摘要**。

**系统不是什么**(这几条是硬约束,不是宣传口径):
- 它**不做**心理诊断、人格判定、情绪识别或任何医疗/精神卫生判断;
- 它**不输出**「是否建议录用」「岗位匹配度」「候选人排名」;
- 它给出的任何倾向性提示都是**低置信度**的,并且会同时给出依据与有效样本量。

## 二、收集哪些数据

| 类别 | 具体内容 |
|---|---|
| 视频 | 摄像头原始录像(1280×720) |
| 音频 | 原始录音,以及从中算出的声学量(音高、能量、停顿结构等) |
| 行为特征 | 面部关键点与动作单元近似值、手部/姿态关键点、上述量的逐帧记录 |
| 转写文本 | 你说话的**文字转写**与逐字时间戳 |
| 元数据 | 设备型号、分辨率、取景距离、光照、面试时间等**协变量** |
| 你填写的 | 姓名、出生年月、性别、院系、专业、所在单位 |

⚠️ **原始录像与录音会整段留存**(这是本项目与其他系统的最大不同 —— 没有原始媒体,
特征算错了就无法重算)。留存位置在本机共享盘,不进入代码仓库。

## 三、用来做什么(两种用途,**请分别勾选**)

依据审查意见(`测评回复_心理测量学审查.md` §7.4 第 8 条),两种用途的同意**必须分开**:

- [ ] **用途 A —— 给你自己的反馈**:把本场的行为观测摘要回给你本人看。
- [ ] **用途 B —— 雇主侧**:向雇主方提供**结构化行为记录**(即"测到了什么量、值是多少、
  有效样本多少")。**雇主侧不会拿到特质量表分、不会拿到"是否推荐"的结论。**

两者可以只选一个。**只选 A 也完全可以。**

## 给实现者的备注(AI 记录,不属于同意书正文)

1. **字段落地**:`session_meta.py` 的 `meta.json` 现在**没有** `name` / `birth` / `department` /
   `major` / `organization` 这几个键。加它们要同时改 schema、`--check-session` 的校验与测试。
2. **PII 面**:`姓名 + 出生年月 + 单位` 三者叠加是强可识别信息,且**与行为特征同目录**。
   建议:① `candidate.age` 存年龄就够研究用,`出生年月`若要收需写明理由;
   ② 这几个键**不得进仓库、不得进报告 HTML**(与 M1「原句不进报告路径」同一条纪律)。
3. **禁止表述**(审查 §8 A 组):同意书与界面里都不得出现"心理测评""人格测评"
   "情绪识别""心理画像""是否录用"等词。本稿已避开。
4. **弹窗是前端改动** ⟹ 会触发 vite 热更新。**录制进行中不要改前端**,否则会打断正在录的那一场。
