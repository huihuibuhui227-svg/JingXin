## 2. 你要跑的验收门(T7)

**前置**
```bash

# 2) 起服务(两个终端)
cd ~/jingxin && ~/miniconda3/envs/jingxin/bin/python -m voice_interaction.api.app   # :8001
cd ~/jingxin && ~/miniconda3/envs/jingxin/bin/python -m face_expression.api.app     # :8000
```
⚠️ **gesture 起不来**(mediapipe 1.0 已移除 `mp.solutions`)—— 预先存在的版本问题,本次不跑;其改动由测试覆盖。

**录一场**
```bash
curl -s -X POST http://127.0.0.1:8001/interview/start | tee /tmp/m1.json
SID=$(~/miniconda3/envs/jingxin/bin/python -c "import json;print(json.load(open('/tmp/m1.json'))['session_id'])")

# ≥5 段(题库 8 题,建议答满);至少一次把 id 放**表单字段**:
curl -s -X POST http://127.0.0.1:8001/interview/answer_audio -F "audio=@ans1.wav" -F "session_id=$SID"
curl -s -X POST "http://127.0.0.1:8001/interview/answer_audio?session_id=$SID" -F "audio=@ans2.wav"

# face 顺带收帧:
curl -s -X POST http://127.0.0.1:8000/analyze -F "file=@frame.jpg" -F "session_id=$SID"
```

**两个坑(不踩)**
1. **8 段音频内容要不同** —— 同一段重复提交 → 每行密度相同 → `_std = 0` → G2 按设计判「本次会话内无变化」而拦下。
2. **只能用 `/interview/start` 铸的 id** —— 自己编的 id 匹配不上报告侧的正则,**报告里什么都看不到**。

**核四条**
| 看什么 | 期望 |
|---|---|
| 落盘 | `ls ~/shared/jingxin_recordings/$SID/` → `session.json` + `transcript.json`(含逐字时间戳) |
| 对上号 | `data/logs/` 下 face/voice 两份日志**文件名含 $SID、首列也是 $SID** |
| 原句不出仓库 | 挑 transcript 里一句独特短语,`grep -rn "<短语>" ~/jingxin` → **0 命中** |
| 报告 | `~/miniconda3/envs/jingxin/bin/python -m report_frontend.report_generator` → 「**话语结构特征**」出现「**连接词密度**」行并**过门出分**(带本场区间 + 有效样本量);其余维度仍「证据缺失」;全篇**无分数与评级** |

## 4. 这一轮学到的、必须带进 M2–M5 的

1. **"测试通过 ≠ 有约束力"这一路又出现 5 次**,形态:抽样唯一性断言(1.86% 假红)、**fixture 恰好 100 字导致分母可被删掉**、空输入契约无守卫、**`listen_for_speech` 的新规则是死代码**(静音也是数据、全零 bytes 是真值)、**只认 query 的 id 会静默降级成 NONE**。
   - 强制动作:**每个测试都要能说出"哪个生产改动会让它变红、红得对不对"**;说不出来就是没约束力。
   - 已常驻:`tests/test_assert_coverage.py`(记录实际执行的断言行)—— 但**它抓不到"缺断言"**,别当成万能。
2. **变异验证必须清 `__pycache__`**:同一秒内"写入→跑→`git checkout` 还原"会**跑变异字节码**,曾造成假红。
3. **阈值/常量一律进数据文件**(带 `_provisional` + 依据)。本轮还修了一处**单位错配**:`_default_n_valid = 10` 是帧级列的阈值,而「连接词密度」每段回答一个样本、题库仅 8 题 → 已为该族单独登记 **5**。
4. **跨任务集成点要在计划里点名**:T3 改文件名没把 `data_loader` 的选取正则列进改动面,导致报告路径**什么都加载不到** —— 只有审查者用真加载器跑了一遍才发现。
5. **WSL 内删文件不还 Windows 磁盘**:`D:\WSL\ext4.vhdx` 只增不减,回收需 Windows 侧 `wsl --manage <发行版> --set-sparse true` 或 diskpart compact(2 GB vosk 模型即此例)。
