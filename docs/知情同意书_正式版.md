## 先说三件让你放心的事

- **这不是考试。** 没有对错,不评分。
- **你可以随时说不。** 不参加、或中途退出,都**不影响任何成绩、评奖、评价或录用决定**。
- **面试由导师进行,系统只做记录与录制** —— 不提问、不评分、不参与对话。

## 一、采集什么

| | |
|---|---|
| **视频** | 摄像头原始录像(1280×720),**整段留存** |
| **音频** | 原始录音,以及算出的音高、能量、停顿等量 |
| **面部 / 姿态** | 关键点与动作单元的**逐帧记录** |
| **转写** | 你说话的**文字转写**(含时间戳) |
| **你填的** | 上面「参与者信息」那几栏 |

> **原始录像会整段留存** —— 有了它,分析算法以后有改进可以重算;没有就永远算不回来了。

### ★ 单独同意:人脸视频(法律要求单独勾选,不与下面合并)

人脸信息属**敏感个人信息**,法律要求**单独同意**。你可以**只同意音频与文本、不同意视频**
—— **不同意视频不影响你参加这次面试**。

- [ ] **我单独同意**:采集并留存我的**人脸视频**,并把它作为本项研究的**分析材料**。

## 二、用来做什么(两种用途,**请分别勾选**)

- [ ] **A —— 反馈给你本人**
- [ ] **B —— 结构化的对外记录**:向 ____________________(接收方)提供「测到了什么量、
      值是多少、有效样本多少」。**对方拿不到任何评分,也拿不到"是否推荐"之类的结论。**

两者可以只选一个,**也可以都不选**(那就只参加面试)。

## 三、你会得到什么 / 可能有什么不便

**可能的不便**:被拍摄会让人有些紧张(这是最常见的反应,我们不会评价你的紧张程度);
长时间看屏幕可能眼疲劳。**本项研究不提供报酬。**

**反馈**:本项研究的**整体结果**会以汇总形式反馈(报告 / 论文)。
**你本人的本场摘要与学业与发展建议,可以应你的要求提供** —— 想要就在下面勾一下。

- [ ] 我希望收到本场的摘要与建议

> 摘要写的是「这一场采集到了哪些量、值是多少、有效样本多少」,**不是评分,也不下结论**。
> 「学业与发展建议」由**团队成员**根据面试交流给出,**不是系统生成的结论**。

## 四、我们怎么保护你

- 原始音视频**不经你同意不对外提供**;**不进代码仓库、不进报告**;对外只发表**去标识的汇总结果**。
- 你的姓名 / 学号记在同意书与 `label.json` 里,用于联系与反馈。**如实说明**:目前 `label.json`
  与录像**在同一个目录**;后续会分开存放。

### ★ 保密协议:本次面试的一切信息,**不向任何形式的社交媒体发布**

- **我们承诺**:本次面试的影像、音频、转写与建议,**不发布**到任何形式的社交媒体 —— 包括
  **微信朋友圈 / 群 / 公众号、微博、小红书、抖音、B 站、知乎、贴吧**。
- 用于**学术报告或对外宣传**,**会另外单独征求你的书面同意**;你不同意就只用于研究分析。
- **请你同样遵守**:不要把面试题目、内容或**其他参与者**的情况发到社交媒体 —— 这既保护你自己,
  也保护别人。

**生成 `.docx` 时踩到的两个坑(下次别重踩)**:

1. **靠"下划线格式 + 空格"做的填写线,在 Word / LibreOffice 里会消失** ——
   段落末尾的空白 run 会被整体裁掉(实测:同一行后面还有字的空位能出线,行尾的不能)。
   试过不换行空格(U+00A0)也不行。**必须用下划线字符 `_`**,或表格底框线。
   `.html` 用的是 CSS 边框所以没这个问题,**只有 `.docx` 要注意**。
2. `.docx` 里正文是**宋体**、标题**黑体**(写进 `w:eastAsia`)。⚠️ **本机(WSL)没装
   宋体/黑体**,本地用 LibreOffice 预览看到的是回退字体(uming/wqy),**不代表你 Windows
   Word 里的样子** —— 在你机器上打开才是最终效果。勾选框用的是 `□`(U+25A1),
   本地低分辨率下看着像 "L",高 DPI 下确认是正常的空心方框。
