## 一、这是一项什么研究

- **研究目的**:建立一套**能追溯依据**的行为观测方法 —— 记录面试中可测的行为量,并如实
  说明「哪些量测到了、哪些没测到、值有多可信」。**不做**心理诊断、人格判定或情绪识别。
- **本场由谁提问**:面试**由导师进行**。**系统在本场只做记录与录制** —— 不提问、不评分、
  不参与对话。面试结束后,系统才会从这段录像算出行为观测摘要。
- **流程**:你参加一次面试;系统同步采集你的视频、音频、面部与姿态关键点、以及语音
  文字转写;结束后生成一份行为观测摘要。
- **方法**:摄像头与麦克风采集 → 逐帧特征计算 → 报告层按一套**带出处的判据**披露哪些线索
  证据充足、哪些不足。
- **谁在做 / 时间与人数**:见文首**研究者填写区**。

## 二、会在你身上采集什么

| 类别 | 具体内容 | 敏感个人信息 |
|---|---|---|
| 视频 | 摄像头原始录像(1280×720),**整段留存** | **是**(人脸 = 生物识别) |
| 音频 | 原始录音,以及从中算出的声学量(音高、能量、停顿结构等) | 声纹属生物识别 |
| 行为特征 | 面部关键点与动作单元近似值、手部 / 姿态关键点的**逐帧记录** | 否 |
| 转写文本 | 你说话的**文字转写**与逐字时间戳 | 否(但含身份线索) |
| 元数据 | 设备型号、分辨率、取景距离、光照、面试时间等**协变量** | 否 |
| 你填写的 | 上面「参与者信息」那几栏 | 姓名 / 学号属个人信息 |

> **原始录像与录音会整段留存。** 这是本项目与其他系统最大的不同:**没有原始素材,特征算错
> 了就永远无法重算**。

### ★ 单独同意:人脸视频(法律要求**单独勾选**,不能与下面的用途合并)

《个人信息保护法》第二十八条把**人脸信息**列为**敏感个人信息**(生物识别),第二十九条
要求处理它必须取得**单独同意**、不得与其他条款捆绑。所以这一栏单独列、单独签。

- **必要性**:本研究的观测对象就是面试中的面部与姿态变化。**没有人脸视频就无法完成观测**,
  也无法在算法有缺陷时用新方法重算同一批帧 —— 后者正是我们坚持留存原始素材的理由。
- **对你个人权益的影响**:人脸视频是**强可识别**信息,且会**整段**留存。保护措施见第五节。
  你可以**只同意音频与文本、不同意视频** —— **不同意视频不影响你参加这次面试**,
  也不影响你拿到第四节的反馈。

- [ ] **我单独同意**:采集并留存我的**人脸视频**,并把它作为本项研究的**分析材料**。

## 四、你会得到什么,可能有什么不便

**你会得到的(这一条是必做,不是可选)**:

- 本场结束后,**行为观测摘要会发给你本人**(**10 个工作日**内)。
- 摘要写的是「**这一场采集到了哪些量、值是多少、有效样本有多少**」,并**逐条注明置信度**。
  它**不是评分,也不下结论** —— 系统目前没有标定样本,所以任何「你属于哪一类」的说法都不
  成立,我们也就不会这么说。
- 团队成员会**结合面试时的交流**,给你一份**学业与发展方面的建议**(选课方向、可以补的
  能力、适合尝试的领域等)。这份建议**由人给出**,依据是「面试交流 + 上面的摘要」,
  **不是系统生成的结论**。

> 请注意区分:**「行为观测摘要」是系统按固定规则算出来的**(附置信度与有效样本量);
> **「学业与发展建议」是团队成员给你的个人意见**。两者都不是测评结论、都不是诊断。

**可能的不便与风险**:

- 被摄像头拍摄会让人**有些紧张**,这是最常见的反应。我们不会评价你的紧张程度。
- 长时间注视屏幕可能带来轻微眼疲劳。目前没有发现其他已知的身体风险。
- 本次研究**不提供报酬**。

## 起草时定下的四处判断(给下一轮看)

1. **「结果反馈」与「学业规划建议」写成两件事。** 摘要 = 系统按固定规则算的(附置信度与
   有效样本量);建议 = **人**给的。**不能**写成"由系统分析结果给出学业规划结论" ——
   会同时撞上 ①系统无标定集、`信度上限:中`、实测覆盖 4–20/20,证据门设计上不出结论;
   ②本仓审查已把"心理测评 / 人格测评 / 情绪识别 / 心理画像"列为禁止表述;
   ③PIPL 第三十条要求如实告知"对个人权益的影响"。

2. **保密协议写成双向的。** 禁止发社交媒体主要是**对团队的约束**(学生是被拍的一方),
   同时请参与者也别发 —— 后者保护的是其他参与者。并单列"对外宣传须另外书面同意",
   把「研究分析」与「对外宣传」分开。

3. **`label.json` 与录像同目录,如实写进第五节。** 那是标注功能的代价(强可识别信息与
   生物识别素材放在一起),不粉饰。

4. **批件号删了,但「过审」这件事没删。** 使用者说暂时是院系内部用表,所以删掉批件号栏位、
   不再自称已过审。但**必须留着那句**「若用于论文发表或对外发布,须先过科技伦理审查」——
   否则这张表就从"内部使用"悄悄变成了"一份声称已审查的同意书",那是告知不实。
   过审后要补:批件号 + 伦理委员会全称与联系方式 + 研究期限与人数(这三项现在没有栏位,
   届时照 v1.0 的结构加回)。
