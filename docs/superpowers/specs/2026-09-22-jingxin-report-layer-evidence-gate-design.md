## 1. 设计文档必须修订的三处前提

### 1.1 §6.3 阶段 1「三个数据集标定,先上线」是许可明确禁止的组合

RecruitView 许可三处互相印证(审查 §1.1,原文逐字):

- CC BY-NC 4.0,"Commercial use is strictly prohibited"、"ACADEMIC RESEARCH USE ONLY"
- 勾选项:"I will NOT use this dataset **or models trained on it** for automated decision making in real-world hiring, employment screening, or **psychological profiling**"
- 政策第 2 条:同上,且"*how* machines perceive behavior"限定为研究用途

**§6.3 阶段 1 正是"数据集标定系数(= models trained on it)+ 招聘场景 + 心理特质 + 商业产品"四件事同时成立。**

**修订为(审查给了两条可选路径,需选一条):**

- (a) **L2 在有自有标注前不上线** —— 数据集标定可以做,但结果只作为离线研究结论
- (b) **数据集线严格限定为离线研究结论** —— 明确写入文档:数据集系数不得进入任何已上线功能,不得进产品、不得进销售材料

两条不互斥,可同时采用。**无论选哪条,"数据集标定 → 先上线"这个组合都必须从 §6.3 移除。**

**另需独立核实(审查建议,尚未做):** MIT 与 First Impressions(ChaLearn)的许可条款。MIT README 只写"须同意使用条款",条款正文不在本地仓库。

### 1.2 §4.4 理由 1 的前提对 f0 类特征是错的

原文理由:"**声学特征可跨语言迁移,语言特征不能**"。

**对 f0 类特征,这个前提不成立。** 普通话的词汇声调压缩了情感语音中的音高变异(审查 §3.3 引 Wang, Lee & Ma 2018 等)。校准集是英语、部署是中文 → **同一列的含义在标定与部署之间变了**。

**修订为:** 结论(文本层与声学层分开)保留,理由替换为剩下的三条 —— 失败模式不同 / 隐私等级不同 / 时间线不同。这三条不受影响。

### 1.3 §6.2 缺《科技伦理审查办法(试行)》要求的伦理审查(强制项)

§6.2 现仅写"具体量表版本与授权需确认"。

**按《科技伦理审查办法(试行)》第 2 条第(一)项**,涉及以人为研究参与者(含"利用个人信息数据")的科技活动**必须通过科技伦理审查**。采集候选人自评量表用于标定正落入该条。2023-12-01 已施行。

**修订为:** 在 §6.2 标注为**强制前置项**,与量表授权并列。

## 2. 红线的精确边界

**红线不在特征维度上,在解读方向上。** 这是本增补最需要被记住的一条。

审查 §7.1 原文要点:

- **Art 5(1)(f)** 的措辞**只覆盖 "infer emotions"**,不覆盖 personality traits
- **Art 3(39)** 的 "emotion recognition system … emotions **or intentions**" 定义宽于禁令,但禁令本身仍只针对 emotions
- **Art 5(1)(g)** 的生物特征分类禁令是**封闭清单**(race / political opinions / trade union membership / religious or philosophical beliefs / sex life / sexual orientation),**明确不含 personality**
- → **职场推断"人格特质"本身不构成 Art 5 禁止行为**
- 招聘/选拔 → Annex III point 4(a),属**高风险**;义务适用日 **2027-12-02**(Reg (EU) 2026/1744 已从 2026-08-02 推迟,该条例一字未动 Art 5(1)(f) 与 (g))
- 中国侧:NMPA 两个Ⅲ类器械先例的触发条件都是"**给出抑郁症相关的诊断结论**"/"**给出…心理疾病…程度的结果**"

| 你的东西 | 违法吗 |
|---|---|
| `brow_furrow_ratio`(眉间收缩率) | **不违法** |
| 报告写"候选人**焦虑水平**高" | **欧盟 Art 5(1)(f) 禁止** |
| `pitch_median`、`pause_ratio`、`au_activity_index` | **不违法** |
| 报告写"**抑郁倾向**" | **触发 NMPA 器械闸门 +《精神卫生法》第 29 条** |
| `gaze_aversion_ratio` | **不违法** |
| 报告写"**回避眼神 = 不自信 / 不诚实**" | 证据为零(DePaulo 2003:gaze aversion d=0.03)+ 全球刻板印象产品化 |
| `symmetry_score`、`head_motion_per_sec` | 不违法 |
| 报告写"**未检测到焦虑特征**" | 缺席证明谬误 + 情绪推断红线 |

**结论:设计文档 §4 的 54 列 L0 与 §5 的 36 个 L1 指标,一列都不违规。** 违规的是报告层把中性行为量翻译成"焦虑 / 抑郁 / 不诚实"。

## 5. ① 的完整清单

### 5.1 证据门规则

**任何指标要进打分,必须四关全过。任一条不过 → 该指标置为"证据不足",不参与加权。**

| 关 | 规则 | 不过时 |
|---|---|---|
| G1 有值 | 非 NaN | 证据不足 |
| G2 非常量 | 会话内方差 > 0,且不落在预先登记的近常量名单 | 证据不足 |
| G3 样本够 | `n_valid_frames` / `n_valid_segments` ≥ 该指标登记的阈值 | 证据不足 |

**G3 的阈值在 ① 阶段用「临时登记值」**,理由:设计文档 §5.1 规矩 1 要求阈值来自标定集、跨会话固定,而标定(M5)当前被 §1.1 的许可与 §1.3 的伦理审查卡住。因此:

- ① 阶段:阈值写在配置文件里,**标 `provisional: true` + 版本号**,取值依据是审计算出的物理下限(如眨眼检测至少需要 2 个完整眨眼周期 → 在 10fps 下 ≥ 20 帧)
- M5 到位后:由标定集替换,**替换即新模型版本**(设计文档 §5.1 规矩 5)
- **禁止**把临时值写成代码里的裸常量 —— 设计文档 §6.3 末句:"门槛由报告给出,不由代码硬编码"
| G4 非代理 | 不在封停名单(5.2),且未被代码标记为代理 | 证据不足 |

**置信度三值化**(直接修 `research_mapper.py:268`):

```
无   : 有效证据数 = 0
低   : 有效证据数 ≥ 1 且 < 半数指标槽
中   : 有效证据数 ≥ 半数,但无外部效标验证
高   : 仅在 L2 标定到位且分布外检测通过后可达(本轮不可达)
```

**硬规则:整维 `confidence = 无` 时,不输出分数,只输出"证据不足"。**

**分数与证据分离:** `matched_indicators` 已经存在(`"0/4"`),但当前不影响输出。改为:分数只在证据数 > 0 时产出。

## 6. 验证方式

1. **零输入回归**:`map_features_to_scores({})` 必须**不再产出分数**,只产出 `evidence_gaps`。作为单测固化。(基线:当前输出 47.08)
2. **真实会话回归**:对 `data/logs/` 下每条真实日志跑完整链路,**断言不再出现"置信度:高"** —— 因为所有可用的 L1 证据都还没到位(见 §4 演进表)。当前基线是 4/5 维为"高"。
3. **封停名单单测**:对 5.2 每一列构造一个会话内常量的合成输入,断言其被拦下。
4. **兜底单测**:断言 `BASELINE_FILL` 与假简历兜底**在 ① 后不可达**。基线:`fluency_score`/`fluency_proxy`/`au4_freq`/`blink_rate`/`text_avg_length`/`reaction_time` 六个槽当前走的就是兜底。
5. **置信度可达性单测**:断言 `"无"` 与 `"低"` 两个取值可被真实取到。
6. **措辞扫描**:`grep` 禁止词表,断言 0 命中。**范围已确认干净**:`templates/dashboard.html`、`report_frontend/data_loader.py`、`app.py` 目前 0 命中;红线词汇集中在 `research_mapper.py` / `report_generator.py` / `visualizer.py` / `feature_engine.py` 四个文件。
7. **回归保护(已建立,直接复用)**:`--stats legacy` 逐格复现现有特征矩阵(实测最大绝对差 1.886e-19)。**注意:① 只改报告层,不改采集层,所以这条防线必须仍然通过。**
