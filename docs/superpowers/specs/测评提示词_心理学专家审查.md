# 背景:一个正在开发的面试行为分析系统

## 系统做什么

候选人对着摄像头回答面试题。系统:
1. 逐帧提取面部(MediaPipe FaceMesh)、手势/姿态(Hands + Pose)、语音(librosa 韵律)特征
2. 汇总成会话级指标
3. 输出 5 个能力维度的分数(逻辑思维 / 抗压能力 / 沟通表达 / 自信程度 / 认知负荷效率)
   并生成一份中文面试评估报告
4. **新目标**:扩展到"心理识别",即人格特质倾向的估计

## 现有数据的真实状况(我做了代码审查,以下都是实测数字)

**采集层大面积失效**(146 个面部列里,方向正确、量测真实的只有约 10 列):
- `au20_lip_stretcher` 与 `au12_smile` 是同一段代码,逐位相同(17105/17105 帧)
- `au7_eye_squeeze + avg_ear ≡ 1.0`(100%),两列只有一个自由度
- `au4_frown`(皱眉)86~92% 的帧为 0 —— 用了错误的 landmark
- `head_pitch` 分子分母是同一对点,恒为 −0.998
- `head_yaw` 是常量偏移(60 个视频里负值数 = 0)
- `symmetry_score` 未除人脸尺度,实际是"人脸在画面中的像素尺寸"的单调函数 → 取景代理
- 眨眼子系统全死:`is_blink` / `blink_rate_per_min` / `eye_closed_sec` 100% 恒 0
- 15 个情绪分量中 7 个结构性恒 0;其余经"单形归一化"互相竞争(跨列确定性负相关)
- 手部特征 87% 的帧为 0(手不入镜);有效帧里 100% 被判为"握拳"(阈值设置错误)
- 一个手势特征 `shoulder_is_calibrated` 与视频帧数相关 r = 0.684,与评分的 |r| 达 0.39
  (是真实手势特征的 3 倍),控制视频时长后掉到 0.014 → 纯时长泄漏

**打分层**(输出那 5 个维度的地方):
- 权重最高的指标(0.4)是从一段**写死的假简历文本**算出的常数,对所有候选人都一样
- 三处"硬编码代理替换",例如"紧张度 := 1 − 面部对称性"、"抖动 := 1 − 手部分数/100"
- 置信度只有"高/中"两档,"无"分支在代码里不可达
- 归一化系数与真实量纲不匹配(如 `×5` 让"注视偏离"恒饱和到最差)
- "超过 X% 人群"的百分位基于一个写死的常模 `[60,60,60,60,60]`
- **零输入也输出完整报告**,并指出"核心优势在于自信度"
- 报告无条件注入"语调丰富 / 眼神交流充分 / 手势自然""未检测到焦虑特征"

## 离线验证的真实性能(这是我做决策的主要依据)

在 2011 条真实面试片段上(每条是"一人一题",12 个标注维度:大五 6 维 + 面试表现 6 维,
由临床心理学家成对比较得出),用用户级 7:1:2 划分、5 个随机种子、随机森林、macro Pearson r:

| 特征集 | 维度 | 行为单模态 r | 控制视频时长后 | 行为+文本融合 r |
|---|---|---|---|---|
| 全部特征(含上述所有坏列) | 1410 | 0.383 | 待测 | 0.395 |
| **只留审查判定"可信"的一阶特征** | **22** | **0.329** | **0.251** | **0.392** |
| 再加"有缺陷但仍是真实测量"的列 | 53 | 0.338 | 0.261 | 0.393 |

三条关键观察:
1. **22 个可信特征 ≈ 1410 个特征的效果**
2. 多加 31 个带缺陷的列几乎无提升(0.338 vs 0.329)
3. **22 个特征里没有任何视频时长列,但控制时长后 r 从 0.329 掉到 0.251** ——
   说明时长通过行为测量本身渗透(回答越长,语音/姿态统计量本身就不同)

## 这个数据集的一个结构性事实

每个候选人的片段长度与评分**在设计层面纠缠**:
- 单看"语音时长"一个变量,对 11/12 个标注维度的 |r| 在 0.29~0.37
- 数据把片段按时长分三桶(<20s / 20–40s / >40s),三桶的评分主成分均值是 **+1.40 / −0.30 / −1.25**
- 也就是说"回答得短"与"评分高"强相关。**这不能靠特征归一化消除**。

## 我已知的限制(不用再告诉我这些)

- r ≈ 0.33 的量级对应"粗粒度倾向提示",不足以支撑招聘决策
- 自评量表有社会称许性偏差
- 三个可用数据集(RecruitView 2011 条 / MIT 138 场 / First Impressions 10000 条 15 秒片段)
  全是英语、固定机位拍摄,而系统是中文、笔记本摄像头,存在域偏移
- 我发现的 thin-slice 文献量级(r ≈ 0.39,Ambady & Rosenthal 1992)与本系统的 0.33 接近 ——
  如果你的判断与此不同,请指出
- 我的离线"文本基线"有循环嫌疑:文本输入里混进了一段 LLM 写的候选人人格分析,
  而那份分析直接点名了 OCEAN 维度 → 文本性能被系统性高估

## 我主动选择"不宣称"的东西 —— 请审查这个选择本身

对应完整文档 §10。我的立场是:

1. 系统对外只宣称「**结构化行为记录 + 低置信度特质提示**」
2. **不宣称**"心理识别结论"
3. **不做**临床诊断,不输出任何疾病相关判断
4. **不做**自动招聘决策 —— 只输出倾向提示 + 置信度,**不给录用建议**
5. 报告里的"证据不足"必须是一等输出(有效样本不够时必须显示"证据不足",
   而不是像现在这样零输入也点出"核心优势是自信度")

**请评审这五条**:
- 这个边界划得对吗?是过宽(仍会误导)还是过窄(放弃了本该能宣称的)?
- 第 1 条的措辞("结构化行为记录 + 低置信度特质提示")在专业上是否站得住?有没有更准确的表述?
- 有没有我**没想到**、但同样应该禁止的表述?

# 请审查的设计

我提出的四层结构:

```
L0 采集层   只输出一阶、按解剖尺度归一、时间基准统一、缺失可辨识的量
            面部 ≈22 列 / 手势 ≈13 列 / 语音 ≈16 列 / 文本(ASR 转写,单列一层)
            + 显式协变量:人脸尺度、肩宽、手部可见比例
                  ↓ 显式公式,无写死系数
L1 状态层   36 个会话级"行为状态"指标(不是特质)
            每个带 公式 / 有效样本量 / 值(不足则 NaN) / 置信度(高·中·低·无)
                  ↓ 每族只选一个代表进 L2(选哪个由标定决定)
L2 特质层   L2-a 大五(主框架),真值 = 候选人自评量表
            L2-b 5 个能力维度,从 L1 导出,不独立采集
            权重只能来自标定,禁止手填;三级回退(数据集预标定 → 自有标注校准 → 完全本地化)
```

# 请逐条回答以下问题

**每条都按这个格式回答**:
- **结论**(明确表态,不要"这取决于")

- **若我的判断错了,需要什么证据才能推翻它**

如果你认为所依据的文献本身有争议(如可重复性危机),请说明。

## Q1:三层链条是否成立

"非言语行为线索 → 会话内行为状态 → 稳定人格特质"这条推理链。

## Q2:36 个指标逐个评估

对每个指标判定属于下面哪一类,并说明:
- **A 有实证共识**(哪些文献支持,效应量大约多少)
- **B 有争议 / 效应量很小**
- **C 民间心理学**(常被认为有效但实证不支持,或已被证伪)
- **D 我不知道**

## Q3:自评量表作为效标是否合适

我打算让候选人在面试后填一份中文大五自评量表(~30–60 题),作为 L2 的真值。
- 这在心理测量学上是否成立?
- **自评与他评的一致度**大约是多少?如果只有 0.4~0.5,那么用行为特征去预测自评,
  得到 0.33 —— 这个数字该如何解读?是"接近自评本身的可测量上限"吗?
- 有没有更合适的效标(他评?结构化访谈?多方法多特质矩阵)?
- 我应该在报告里如何表述"自评"这件事,才不误导用户?

## Q4:5 个能力维度与大五的关系

现有 5 维:逻辑思维 / 抗压能力 / 沟通表达 / 自信程度 / 认知负荷效率。
- 这些是**人格特质**还是**任务能力**?两者在测量上能否从同一批行为线索导出?
- "自信程度"与大五的"外向性+低神经质"是什么关系?是同一个构念吗?
- "认知负荷效率"在大五里有没有对应位置?如果没有,它属于什么构念?
- 我打算把大五当第 1 层、这 5 维当第 2 层(从 L1 导出)。这个层级关系合理吗?
  还是应该并列为两个独立量表?

## Q5:部署门槛
