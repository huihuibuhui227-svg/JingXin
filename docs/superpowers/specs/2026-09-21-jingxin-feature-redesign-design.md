## 1. 背景与问题

### 1.1 系统要做什么

一场真实面试 → 三个模块采集行为数据 → 报告层输出评估结果。系统同时要服务两件事:

1. **面试评估**(现有):5 个能力维度 —— 逻辑思维 / 抗压 / 沟通表达 / 自信程度 / 认知负荷效率
2. **心理识别**(新增目标):以人格特质为框架的倾向估计

### 1.3 离线实验的可用结论

对 2011 条 RecruitView 数据,用同一套融合协议(用户级 7:1:2、5 seeds、macro Pearson r):

| 特征集 | 维度 | `beh_rf` | `beh\|dur` | `fus_rf` | Δfus-beh |
|---|---|---|---|---|---|
| 基线(原 9 统计量聚合) | 1410 | 0.3830 | 待跑 | 0.3952 | +0.0123 |
| **C 白名单**(只有可信测量) | **22** | 0.3290 | 0.2513 | **0.3920** | **+0.0630** |
| C+(含带缺陷的真实量) | 53 | 0.3380 | 0.2606 | 0.3925 | +0.0545 |

**三条结论**

1. **22 个一阶可信特征 ≈ 1410 维的效果**(`fus_rf` 0.3920 vs 0.3952)。这是"维度少而可信"优于"维度多而混杂"的直接证据。
2. **C+ 几乎不比 C 好**(0.3380 vs 0.3290,差 0.009 ≪ 种子 std 0.04)→ 问题**不是"维度太少"**,多出的 31 个带缺陷列基本是死重。
3. **C 里没有任何时长列,却仍有 23% 的信号与时长相关**(0.3290 → 0.2513)→ 时长通过**行为测量本身**泄漏(回答越长,语音/姿态统计量本身就不同)。

**限制**:0.329 vs 0.383 仅约 1 个标准差,正确说法是"统计上分不出高下",不是"22 维更好"。

### 1.4 为什么必须重构而不是打补丁

现有 191 列里,审查判定"方向正确、量测真实"的只有约 10 列(面部)。其余是恒定、代理、单位错、或"多列承载同一自由度"。聚合出的 1410 维里 **169 个取值只在 {0, 1, −1}**。在这个基础上做重要性归因或心理结论,得到的是取景、机器负载与视频长度的函数。

## 2. 目标与非目标

### 2.1 目标

1. **L0 采集层**只输出一阶、按解剖尺度归一、时间基准统一、缺失可辨识的量
2. **L1 状态层**用显式公式构造会话级行为指标,每个指标带有效样本量与置信度
3. **L2 特质层**以大五为主框架,真值来自候选人自评量表;权重由标定学习,禁止手填
4. **标注与采集解耦**:采集端不知道标注;标注异步、累积、可缺失
5. **可回归**:每层都有可复跑的验证,特征集每次变更必须重跑标定

### 2.2 非目标

1. **不做临床诊断**,不输出任何疾病相关判断
2. **不做自动招聘决策**:系统输出倾向提示 + 置信度,不输出录用建议
3. **不重抽历史数据**:系统处理未来会话,修好采集代码即可;重抽只对已停的论文线有意义
4. **不在本轮引入新模态**(不做 Praat 全套、不做 VLM 语义理解)
5. **不保留现有 1410 维聚合方式**(9 统计量 → 1 个)

### 4.4 L0-T 文本层(新增)

**不与 L0-A 合并的四个理由**

1. **跨语言可迁移性不对称(仅适用于非 f0 类特征)** —— 语言特征不能跨语言迁移。注意:f0 类特征是**例外**,普通话的词汇声调压缩了情感语音中的音高变异,故 f0 类特征同样不可跨语言直接搬运(增补 §1.2)。三个数据集全是英语,中文词汇特征一个都借不上。合并会让这个差别隐身。
2. **失败模式不同**:ASR 错字 vs 声学估计噪声,需分开统计与降级。
3. **隐私等级不同**:转写文本是内容,保留策略/脱敏/留存期应与声学数值分开。
4. **时间线不同**:声学可实时逐块,转写可流式可后处理。

**基础(必须落盘)**

- `transcript_raw` —— 整段转写文本
- `transcript_segments` —— 带逐字/逐段毫秒时间戳
- `asr_confidence` / `asr_model_version` —— 缺失则出错无法归因

**派生(中文特定,不可跨语言迁移)**

| 类 | 指标 |
|---|---|
| 长度 | 字数、不重复字数(TTR)、平均句长 |
| 结构 | 连接词密度、自我打断次数、修正/重复次数 |
| 内容 | 与问题相关性、关键词覆盖、具体度(数字/专有名词比例) |
| 语义 | 句向量 embedding(**先进 L1 观望**,不直接进 L2) |

**两条规矩**

1. 所有 LLM 参与产出的特征必须带 `source='llm'`,**不可与人工标注或机器测量混存**
2. `asr_confidence` 低的片段,其派生特征置 NaN 或降权——否则 ASR 错误会伪装成"表达不流畅"

### 4.5 两条贯穿全清单的规矩

1. **凡是"取景/设备/机器负载"会影响的列,要么按解剖尺度归一,要么显式输出为协变量。** 让模型能看见并控制它们,而不是让它们藏在别的列里——审查里最毒的三条(`symmetry_score`、iris 四列、手部十列)全是这个病。
2. **每一列都要在标定里被证明有用;证明不了就删。** 不要因为"看起来像心理指标"而留着。

### 4.6 L0 规模

| 模态 | 现在 | L0 |
|---|---|---|
| 面部 | 146 列(→1260 维) | ≈22 逐帧列 |
| 手势 | 35 列(→140 维) | ≈13 列 |
| 语音 | 10 列 | ≈16 列 |
| 文本 | — | 3 基础 + 派生(延后) |
| **合计** | **191 列 / 1410 维** | **≈54 列** |

## 5. L1 会话级指标

### 5.1 五条设计规矩

1. **定义"发生/未发生"的阈值必须来自标定集,跨会话固定。禁止两件事:(a) 写死无出处的常数;(b) 用视频内分位定义事件。**

   为什么禁止 (b)——这条容易踩:若写成 `smile_ratio = au12 > p90(au12) 的占比`,**视频内 p90 按定义永远选出约 10% 的帧**,于是该指标对每个人都 ≈ 0.10,零信息量。这与审查中 `speech_ratio` 的"自指阈值"是**同一类错误**(用被测量自身的均值/分位当基准)。

   正确做法:**阈值是模型工件的一部分**——在标定集上拟合(如 `au12` 的 p90 取自常模人群),上线时固定使用,与会话无关。

   视频内分位**只允许用于归一化,不允许用于定义事件**:`gaze_stability = 1 − std/视频内极差` 这类是合法的(它把个体差异缩放到可比区间),但"是否发生一次偏离"必须用固定阈值。

   教训:`focus_score` 写死 3 个值 → 99.7% 恒 0.3;`fist_threshold=0.08` → 100% 判握拳;`max_shrug_diff=0.1` → 几乎测不出。
2. **只出"率"和"分布",不出"总量"。** 总量与时长纠缠,正是 1410 维里 65% 信号的来源。
3. **每族只放一个代表进 L2。** 否则同族多指标平分权重。
4. **每个指标必须带有效样本量。** 不足 → NaN,不填默认值。
5. **标定阈值随模型版本号一起存储与版本化。** 阈值变了就是新模型,必须重跑标定报告。

## 6. L2 特质估计层

### 6.1 两个子层

| | L2-a 大五(主) | L2-b 五维能力(任务视图) |
|---|---|---|
| 真值 | 候选人自评量表 | 无独立真值 |
| 来源 | 独立采集 | **从 L1 导出** |
| 用途 | 心理识别的标准框架 | 招聘报告 |

**为什么用大五**:唯一同时具备(a)公认量表可对照、(b)三个数据集均有标注、(c)行业默认解释框架三项条件的框架。现有 5 维是任务能力,不是人格特质;分两层后各归其位。

### 6.2 标注机制

```
面试结束 → 候选人自评量表(~30–60 题,3–5 分钟)   ← 唯一必需的人工投入
        → sessions/{session_id}/labels.json
           { source: "self_report", instrument: "<量表名+版本>", collected_at, items: {...} }
可选 → 人工评表现   { source: "human" }
可选 → LLM 评表现   { source: "llm" }             ← 三者不可混存
```

- **首选自评而非人工**:大五本来就是自评量表测的;人工评是第二等替代且贵;自评拿到的是构念的标准真值,成本约 5 分钟候选人时间
- 具体量表版本与授权需确认后使用
- **⚠️ 强制前置项:** 按《科技伦理审查办法(试行)》第 2 条第(一)项,以人为研究参与者(含"利用个人信息数据")的科技活动**必须通过科技伦理审查**。采集候选人自评量表用于标定落入该条,2023-12-01 已施行。此项与量表授权并列,不得省略。
- **允许缺标注**——L2 的设计前提就是标注可迟到、可部分

### 6.3 三级回退(不阻塞上线)

> ⚠️ RecruitView 许可(CC BY-NC 4.0)明文禁止将本数据集**及在其上训练的模型**用于真实招聘、雇佣筛选或**心理画像**。故"数据集标定 → 先上线"这一组合被移除。详见增补 §1.1。

| 阶段 | L2 映射来源 | 置信度上限 |
|---|---|---|
| 1 | 三个数据集标定(**不上线**,仅作离线研究结论) | 低(仅限离线) |
| 2 | 自有标注足够支撑校准 → 校准 | 中 |
| 3 | 标注量足以做独立验证 → 完全本地化 | 高 |

阶段 1 不再是上线路径:数据集系数只能作为离线研究结论存在,其合法去向只有两条(增补 §1.1):

- **(a) 有自有标注前 L2 不上线** —— 数据集标定可以做,结果只作为离线研究结论
- **(b) 数据集线严格限定为离线研究结论** —— 明确写入文档:数据集系数不得进入任何已上线功能,不得进产品、不得进销售材料

两条不互斥,可同时采用。对已上线功能而言,阶段 2 才是第一个可用的映射来源;上表阶段 1 的置信度上限"低"只在离线研究语境下成立。

进入阶段 2 的门槛不写死场次数,而是**由统计功效定**:以 13 个 L1 代表为自变量、单个 L2 维度为因变量,要求相关系数的标准误低于预设上限(例如 0.08),据此反推所需样本量,写入标定报告。**门槛由报告给出,不由代码硬编码**——这与 6.5 的"权重只能来自标定"是同一条原则。

### 6.4 标定流程(离线,复用已建 harness)

1. **分布对齐检查**:同一 L1 指标在数据集与自有会话上的分布可比性(KS / 分位数对照)。**不可比的指标,其数据集系数不可直接搬。** 域偏移:语言、设备、取景、题库全不同。
2. **相关性矩阵**:13 个 L1 代表 × L2 维度,r + 置信区间 + 样本量。
3. **族内选代表**:在上一步顺带定。
4. **拟合映射 + 交叉验证**。

### 6.5 四条硬约束

1. **权重只能来自标定,禁止手填。** 现有 5 维权重是手写的,且 `comm` 维度和为 1.4——这个 bug 本身就是没有标定把关的结果。
2. **置信度必须能取"低"和"无"。** 由 L1 的 `n_valid` + 标注量 + 分布外检测共同决定。
3. **百分位只能来自真实常模。** `[60,60,60,60,60]` 必须删。
4. **不许无条件注入描述。** "语调丰富/眼神交流充分/手势自然""未检测到焦虑特征"必须删。

### 6.6 输出形态

```json
{
  "session_id": "20260921_143052_a1b2c3",
  "traits": {
    "openness": { "estimate": 0.42, "ci": [-0.18, 0.78], "confidence": "低",
                  "basis": ["au_activity_index", "speech_rate"],
                  "n_labels_used": 0, "calibration_stage": 1 }
  },
  "capabilities": {
    "logical_thinking": { "estimate": 58.2, "confidence": "中",
                          "basis": ["discourse_marker_rate", "response_latency_sec"],
                          "evidence_gaps": ["logic_keyword_density: 需 ASR 文本(M1)"] }
  },
  "evidence_gaps": ["blink_rate: 有效帧不足(182/1200)", "hand: 全程未入镜"]
}
```

L2-b 的取值域沿用现有 0–100 量纲以兼容报告模板,但**权重与常模都必须来自标定**,且必须带 `confidence` 与 `evidence_gaps`。

`evidence_gaps` 是**一等输出**。零数据时必须显示"证据不足",而不是点出"核心优势是自信度"。

## 8. 验证策略

1. **回归保护(已建立,直接复用)**:`--stats legacy` 模式逐格复现现有特征矩阵(实测最大绝对差 1.886e-19,0/2835510 格差异)。改采集代码后必须仍然通过。
2. **合成信号单测**:对每个一阶量构造已知真值的合成输入,断言输出。审查中已用此法确认了 `speech_ratio` 失效与尾部停顿 bug——沿用。
3. **量纲/归一化检查**:每个归一化量的实测取值域必须落在物理范围内(如 `au26` 不饱和、`pitch_mean` < 400 Hz)。
4. **特征变更回归测试**:每次改特征集,必须重跑"L1 → 标注"的相关性并对齐基线;否则不知道改对还是改错。**这是把 harness 固化成流程,不是一次性检查。**
5. **标定报告作为门槛**:L2 上线的必要条件是一份含样本量、置信区间、分布对齐检查的标定报告。

## 9. 分阶段实施顺序

| 里程碑 | 内容 | 依赖 |
|---|---|---|
| **M1** | **ASR 落盘**(文本 + 时间戳 + 置信度 + 模型版本)+ 修 session_id 链路 | 无。立刻修掉打分层权重 0.4 的空指标;逐字时间戳为 L0-A 的率类特征铺路 |

| **M3** | L0 逐列重构(面部 → 手势 → 语音) | M2 |
| **M4** | L1 指标层 + 元数据结构 + `evidence_gaps` | M3 |
| **M5** | L2 标注机制 + 标定流程 + 三级回退 | M4 + 标注开始收集 |

**M1 独立可交付**,不依赖特征设计完成。

**M2 可先于 M3 独立上线**:fps / timestamp / 序列化 bug / 微表情窗口都是确定的缺陷修复,不改变任何列名,不影响打分层。

## 10. 已知限制与不宣称的东西

1. **精度天花板**:离线验证的 macro r ≈ 0.33(单个目标约 0.2–0.4),且 22 维 vs 1410 维的差异仅约 1 个标准差。**能做粗粒度倾向提示,不足以支撑招聘决策。**
2. **系统该宣称的是**「结构化行为记录 + 低置信度特质提示」,**不是**「心理识别结论」。做到后者需要更长会话、更多模态、以及完整的心理测量学验证(重测信度、与既有量表的聚合效度)。
3. **自评量有社会称许性偏差**,且自评与他评本身存在已知差异。它是首选真值,不是完美真值。
4. **域偏移**是真实的:数据集为英语、固定机位、拍摄视频;系统为中文、各自坐姿、摄像头。数据集系数不可无检查地迁移。
5. **离线的文本基线有循环嫌疑**:`run_fusion.py` 的文本输入是 `transcript + gemini_summary`,而后者是 LLM 写的人格分析,直接点名了 OCEAN 维度。`text_rf ≈ 0.354` 被系统性高估。系统线不应指望文本有该量级表现。
6. **C 里仍有时长泄漏**(0.3290 → 0.2513),说明时长通过行为测量本身渗透,特征归一化消除不掉设计层面的纠缠。

## 11. 待定与开放问题

1. **`response_latency` 依赖"问题结束时间戳"**。用户反馈:采集流程暂无问题时间戳,将通过 ASR 落盘尽量带入。**在具备之前,该指标降级为"首段静音时长"或删除。**
2. **具体用哪份中文大五自评量表**(版本与授权待确认)。
3. **L2-a 与 L2-b 的合成方式**:L2-b 从 L1 导出,是独立拟合还是由 L2-a 推导,待标定数据显示哪条更稳。
4. **手势块是否值得保留**:取决于手的入镜率。若长期偏低,G 族整体降级。
5. **`handedness` 左右侧是否整体互换**(审查高置信但未验证):MediaPipe Hands 假定输入镜像,而全链路无 `cv2.flip`,内部证据(`head_tilt ≈ 176°`)显示画面未镜像。需一段已知哪只手在动的片段验证。
6. **文本层哪些指标真正有用**:必须等标注,不能凭直觉定。
